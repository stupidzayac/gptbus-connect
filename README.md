# GPTBus Connect

登录 GPTBus，在 Codex CLI 或 Claude Code 里使用你的模型。

## 下载

| 你的电脑 | 下载 |
| --- | --- |
| Windows | [Intel 或 AMD](https://github.com/stupidzayac/gptbus-connect/releases/download/v1.1.0/GPTBus-Connect-v1.1.0-win-x64.zip) · [ARM 电脑](https://github.com/stupidzayac/gptbus-connect/releases/download/v1.1.0/GPTBus-Connect-v1.1.0-win-arm64.zip) |
| Mac | [Apple 芯片（M 系列）](https://github.com/stupidzayac/gptbus-connect/releases/download/v1.1.0/GPTBus-Connect-v1.1.0-osx-arm64.zip) · [Intel 芯片](https://github.com/stupidzayac/gptbus-connect/releases/download/v1.1.0/GPTBus-Connect-v1.1.0-osx-x64.zip) |
| Linux | [Intel 或 AMD](https://github.com/stupidzayac/gptbus-connect/releases/download/v1.1.0/GPTBus-Connect-v1.1.0-linux-x64.zip) · [ARM 电脑](https://github.com/stupidzayac/gptbus-connect/releases/download/v1.1.0/GPTBus-Connect-v1.1.0-linux-arm64.zip) |

下载后解压，打开 GPTBus Connect。如果不确定 Mac 的芯片型号，可在苹果菜单的「关于本机」中查看。

## 开始使用

1. 打开 GPTBus Connect，选择已经安装的 Codex CLI 或 Claude Code。
2. 点击「登录 GPTBus」，在打开的官网核对账号和识别码，再点击「允许并返回工具」。还没登录时，可使用平时的 GPTBus 登录方式。
3. 回到工具后，从自动加载的列表中选一个模型，点击「连接 GPTBus」。新开终端窗口，运行 `codex` 或 `claude` 开始对话。

已有密钥也可以展开「手动输入密钥」并粘贴使用。若只想试用，可在官网授权时把这台设备的消费上限设为 US$0.50。

工具会备份连接前的设置。要切回原设置，点击「恢复原设置」。要停用设备密钥，请在 GPTBus 控制台的「API 密钥」中停用对应的 GPTBus Connect 记录。
