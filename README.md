# GPTBus Connect

用你的 GPTBus 密钥，在 Codex CLI 或 Claude Code 里开始对话。

## 下载

| 你的电脑 | 下载 |
| --- | --- |
| Windows | [Intel 或 AMD](https://github.com/stupidzayac/gptbus-connect/releases/download/v1.0.1/GPTBus-Connect-v1.0.1-win-x64.zip) · [ARM 电脑](https://github.com/stupidzayac/gptbus-connect/releases/download/v1.0.1/GPTBus-Connect-v1.0.1-win-arm64.zip) |
| Mac | [Apple 芯片（M 系列）](https://github.com/stupidzayac/gptbus-connect/releases/download/v1.0.1/GPTBus-Connect-v1.0.1-osx-arm64.zip) · [Intel 芯片](https://github.com/stupidzayac/gptbus-connect/releases/download/v1.0.1/GPTBus-Connect-v1.0.1-osx-x64.zip) |
| Linux | [Intel 或 AMD](https://github.com/stupidzayac/gptbus-connect/releases/download/v1.0.1/GPTBus-Connect-v1.0.1-linux-x64.zip) · [ARM 电脑](https://github.com/stupidzayac/gptbus-connect/releases/download/v1.0.1/GPTBus-Connect-v1.0.1-linux-arm64.zip) |

下载后解压，打开 GPTBus Connect。如果不确定 Mac 的芯片型号，可在苹果菜单的「关于本机」中查看。

## 开始使用

1. 打开 GPTBus Connect，选择已经安装的 Codex CLI 或 Claude Code。
2. 粘贴你的 GPTBus 密钥，点击「获取可用模型」，选择要使用的模型。
3. 点击「连接 GPTBus」，新开终端窗口，运行 `codex` 或 `claude` 开始对话。

密钥保存在这台电脑上。想切回之前的设置，打开 GPTBus Connect，选择同一个客户端，点击「恢复原设置」。
